# The Bagley Board

The Bagley Board is an educational game made in Unity inspired by Mario Party, with two unique minigames.

With a unique prototype board inspired by this tutorial: https://www.youtube.com/watch?v=W8ielU8iURI.  
[!Lana's Board]()

A minigame inspired by the famous concurrency problem: The dinining philosophers problem. Where you will play as philosophers such as, Sartre, De Beauviour, Aristotle and Kant, battling to deadlock the other player from taking a fork.
[!Dining Philosohers]()

The other minigame tests your low-level skills by adding unsigned 7 bit binary numbers.
[!Binary Addition]()

A winner will be selected once a minigame ends.
[!Winner screen]()

You can play the game by downloading the build in the release. Currently, there's builds for Windows, MacOs and Linux.
